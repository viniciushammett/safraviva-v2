Fixtures: decoded RGBA pixels (256 × 256 × 4 bytes), compressed with zlib,
from the official OSM block images downloaded on 2026-11-08. Used to verify
the SHA-256 signatures without a network connection or a PNG dependency.
No color conversion, resizing or pixel changes were applied.

- `osm-403.rgba.deflate`: [403 tile.png](https://wiki.openstreetmap.org/wiki/File:403_tile.png), uploaded by Pnorman.
- `osm-403r.rgba.deflate`: [403r tile.png](https://wiki.openstreetmap.org/wiki/File:403r_tile.png), uploaded by ElementW.

Source stated by both pages: OpenStreetMap Fastly configuration.
